# Product Vision & User Stories

## Vision
To enable YouTube users to quickly digest video content without watching the entire video, by providing instant, high-quality summaries generated by Google's Gemini 3.0 Flash model directly within the YouTube interface.

## Use Cases
1.  **Educational Videos**: Quickly grasp the key concepts of a lecture or tutorial.
2.  **News & Updates**: Get a digest of current events from news clips.
3.  **Podcasts/Interviews**: Find specific topics or takeaways from long-form content.
4.  **Content Filtering**: Decide if a video is worth watching based on the summary.

## User Stories
1.   **As a user**, I want to see a "Summarize" button next to the YouTube video controls so that I can easily trigger a summary.
2.   **As a user**, I want the summary to appear in a side panel so that it doesn't obstruct the video player.
3.   **As a user**, I want to provide my own Gemini API key so that I have control over usage and limits.
4.   **As a user**, I want the summary to be concise and accurate so I can trust the information.
5.   **As a developer**, I want to easily package the extension for distribution.

## Future Enhancements
-   **As a user**, I want to ask questions in a prompt box below the summary so that I can get more information from the transcript. 
-   **As a user**, I want to be able to save the last 5 summaries so that I can read it later.
-   **As a user**, I want to be able to easily pick between the last 5 summaries so that I can read it later.
